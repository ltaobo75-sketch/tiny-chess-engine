A 4 KB Python chess engine: 0x88 board, alpha-beta with a transposition table, killer moves and quiescence search, iterative deepening to a fixed 40,000-node budget per move (never a clock), material plus piece-square evaluation. The source is LZMA-compressed inside main.py, as the rules allow.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
